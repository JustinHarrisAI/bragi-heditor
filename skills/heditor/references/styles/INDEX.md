# Named styles

Each file is a reproducible visual language. Rebuild the scenes from the new speech every time; never stamp a previous edit.
All fonts mentioned in the styles are installed by `setup.sh` and copied into each cut by `rk.setup_assets()` (Anton, VT323, Geist, Inter, JetBrains Mono, IBM Plex Mono, Press Start 2P, Playfair Display, Fraunces, Bebas Neue, DM Serif Display, Caveat, B612 Mono, Fredoka). Music ids refer to `assets/catalog.json`. A few newer styles use extra OFL families from google/fonts that you download into the cut with their `OFL.txt` (Bungee, Alfa Slab One, Tilt Neon, Barlow Condensed, IBM Plex Sans Condensed); each style file says which.

Styles marked **ad** are paid-traffic formats with a "Learn more" CTA and the ad safe area (`../captions-and-layout.md`, Paid-ad variant). Styles marked **authority** are serious formats where the speaker is the expert (sober palette with one accent, large central camera with a true name strip, the rule as the on-screen title).

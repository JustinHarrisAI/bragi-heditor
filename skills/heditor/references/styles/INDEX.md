# Named styles

Each file is a reproducible visual language. Rebuild the scenes from the new speech every time; never stamp a previous edit.
All fonts mentioned in the styles are installed by `setup.sh` and copied into each cut by `rk.setup_assets()` (Anton, VT323, Geist, Inter, JetBrains Mono, IBM Plex Mono, Press Start 2P, Playfair Display, Fraunces, Bebas Neue, DM Serif Display, Caveat, B612 Mono, Fredoka). Music ids refer to `assets/catalog.json`.

| Style | Display name | Best for | Energy | Camera | Captions |
|---|---|---|---|---|---|
| [`cinema`](cinema.md) | Cinema | arguments with several turns; one metaphor per beat | high | live card that moves between hero and top | Anton kinetic, pill or gold active word |
| [`ruptura`](ruptura.md) | Ruptura | a speech with one killer line and a "you vs everyone" contrast | high | the camera itself becomes the metaphor (clones, split, freeze) | Anton with light-yellow pill |
| [`impacto`](impacto.md) | Impacto | explanations that need calm readability with two hard-hitting moments | medium | stable below a board of argument cards | Geist on a gold seam |
| [`game`](game.md) | Game (retro RPG) | learning, unlocking, levelling up, tools/skills, routines | playful | pixel character window | RPG dialog box, typed word by word |
| [`thriller`](thriller.md) | Thriller | risk, failure, security, "what if it breaks" stories with recovery | tense → hopeful | full-width CCTV feed, blackout, CRT power-on | film subtitles, keyword blinking red |
| [`ide`](ide.md) | IDE | programming, automation, scripts, tooling | focused | circular webcam bubble over an editor | typed as code comments, selection highlight |
| [`aeroporto`](aeroporto.md) | Aeroporto (control tower) | approval flows, processes, launches, deploys, checklists | tense → release | CRT monitor in the tower console | radio transmission, amber active word |
| [`chat`](chat.md) | Chat (light messenger) | communication, prompts, customer service, instructions | light | video-call window and PiP | the speaker's messages, highlighter on the active word |
| [`documentario`](documentario.md) | Documentário | personal stories, careers, decisions, reflective topics | emotional | letterbox band with slow push-in | serif documentary subtitles, underlined active word |
| [`missao`](missao.md) | Missão (open-world game homage) | life goals, careers, "levelling up" stories, myths vs reality; base for open-world game references | high, cinematic | warm sunset-graded feed inside phone clips and cards, freeze-frame intro | white on saturated magenta active word |
| [`podcast`](podcast.md) | Podcast (talk show) | opinions, soft skills, debates, energetic speakers | very high | tilted editorial card with hard shadow | giant karaoke, one word at a time |

Not listed? Use creative mode (`../creative-mode.md`) and, if the user likes the result, add the new style (`../adding-styles.md`).
